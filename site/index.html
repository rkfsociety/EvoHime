Local AI Agent for Windows with a Supervised Runtime

EvoHime (Eva) is an open-source AI Coding Assistant that runs locally on Windows. It understands your workspace, executes tasks with explicit approval gates, and connects to Ollama, OpenAI-compatible APIs, LiteRouter, or local Codex CLI.

Built for Real Local Engineering Work

Every boundary is explicit: the UI never touches SQLite or your workspace directly, and sensitive operations always pause for your approval.

01 / RUST CORE

Rust Core Runtime

High-performance native Rust runtime owns workspace access, tool execution, local SQLite state, and permission enforcement without external Node.js dependencies.

02 / ELECTRON UI

Clean Desktop Interface

Focused Electron desktop client with English and Russian UI, live execution tracking, scheduled task view, persistent memory overview, and saved chat histories.

03 / SUPERVISED RUNTIME

Windows Supervisor & Isolation

A dedicated supervisor process isolates the process tree via Windows Job Objects, authenticates local named-pipe IPC, and recovers the core after unexpected crashes.

04 / FLEXIBLE PROVIDERS

Ollama & OpenAI-Compatible APIs

Run fully local models with Ollama or connect OpenAI-compatible APIs, OpenAI Responses API, LiteRouter, and local Codex CLI — switch models right before any task.

System Requirements

  • Windows 10 (version 2004 or later) or Windows 11
  • 64-bit (x64) architecture
  • No separate Node.js or Rust installation required for end users
  • Single web installer (EvoHime-Setup.exe) for install and repair

Privacy & Security by Design

  • Workspace data and chat histories remain stored locally in SQLite
  • API keys are encrypted with Windows DPAPI and never shown in UI
  • File edits, commands, and recovery steps require explicit confirmation
  • Open-source under the MIT License for transparent auditing
