# Дизайн окна обновления EvoHime

Утверждённый визуальный референс хранится в
[`.codex/updater-window-preview.html`](../.codex/updater-window-preview.html).
Это канонический макет для Electron package `updater\EvoHimeUpdater.exe`,
который выпускается вместе с Rust worker единым модулем `updater`.

## Визуальный контракт

- компактное вертикальное окно примерно `520 × 680` px с минимальным размером
  `420 × 560` px;
- тёмная одно-колоночная оболочка EvoHime без декоративного левого rail,
  рекламного текста и крупных иллюстративных индикаторов;
- верхняя строка `EvoHime / Обновление` с системными действиями свернуть и
  закрыть, без окна консоли Windows;
- в основном содержимом — заголовок состояния, короткое понятное сообщение,
  строка прогресса применения модулей и компактный список компонентов;
- в строке компонента показываются только название, короткое назначение и
  установленные/доступные версии;
- нижние действия закреплены у края содержимого: закрытие слева, обновление
  (если доступно) и основной запуск справа;
- состояния должны быть визуально различимы: проверка, готово, доступно
  обновление, ошибка проверки, восстановление и выполнение обновления;
- технические recovery-метаданные не показываются в обычных состояниях.
  При ошибке или восстановлении пользователю выводится только короткая
  полезная детализация из UI-статуса;
- ошибки показываются понятным текстом, без необработанных внутренних форматов
  и без автоматического закрытия окна.

Макет является контрактом композиции и цветов. Пользовательское окно должно
оставаться Electron/React-интерфейсом и не должно возвращаться к стандартной
серой Win32-форме с необъяснимыми полями и видимым терминалом. Проверка и
применение выполняются отдельным headless Rust worker’ом, а renderer только
отображает типизированный статус через preload IPC.
