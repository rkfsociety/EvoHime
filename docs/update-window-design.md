# Дизайн окна обновления EvoHime

Утверждённый визуальный референс хранится в
[`.codex/updater-window-preview.html`](../.codex/updater-window-preview.html).
Это канонический макет для независимого нативного `evohime-updater.exe`.

## Визуальный контракт

- тёмная оболочка EvoHime с мягким синим/бирюзовым свечением;
- верхняя строка `EvoHime / Обновление` без окна консоли Windows;
- слева — короткое объяснение безопасного запуска и визуальный индикатор;
- справа — заголовок состояния, список модулей с версиями, прогресс и итог;
- одна основная кнопка действия и вторичная кнопка закрытия;
- состояния должны быть визуально различимы: готово, доступно обновление,
  ошибка проверки и выполнение обновления;
- ошибки показываются пользователю понятным текстом, без необработанных
  внутренних форматов и без автоматического закрытия окна.

Макет является ориентиром композиции и цветов. Нативная реализация может
использовать Win32-отрисовку, но не должна возвращаться к стандартной серой
форме с необъяснимыми полями и видимым терминалом.
