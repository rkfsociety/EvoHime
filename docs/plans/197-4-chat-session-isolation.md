# План 197.4 — Verification, документация и release evidence

Статус: active implementation contract. Этап закрывает план 197 после
реализации 197.1–197.3.

## Scope и изменяемые контракты
1. **Сквозная проверка (CI и E2E):**
   - Real-Core E2E сценарий: одновременный запуск двух чатов с разными
     провайдерами/моделями и разными `PermissionMode` (`read_only` vs `full`)
     без перезапуска Core; проверка независимости событий, ответов и отмены.
   - Сценарий `isolated_worktree`: два параллельных пишущих чата в одном
     тестовом git-репозитории без взаимного повреждения файлов.
   - Проверка прохождения всех CI workflows (`rustdoc`, Rust tests, Electron
     `check:protocol`, `typecheck`, `test`, `check:bundle`).
2. **Актуализация канонической документации:**
   - Перенести утверждённый контракт изолированных сессий чата (per-run
     `SessionBinding`, мульти-маршрутный `ModelGateway`, per-chat `chats.json`
     и опциональный `git worktree`) в доменный файл `docs/architecture/`
     (соблюдая лимит ≤ 2000 строк).
   - При изменении общих границ/инвариантов обновить `docs/architecture.md`
     (лимит ≤ 500 строк).
   - Обновить `docs/current-state.md` и `docs/release-evidence.md`
     фактическими результатами проверок и коммитом.
3. **Закрытие плана:**
   - После подтверждения всех критериев готовности удалить временные файлы
     `docs/plans/197-*.md` и убрать `197` из активного каталога в
     `docs/plans/README.md` (перенеся в закрытые направления).
