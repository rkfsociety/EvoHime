# План 191.4 — verification, release evidence и закрытие

Статус: active implementation contract. Этап следует после overview 191.0 и
предыдущих этапов этого направления.

## Scope и изменяемые контракты

Закрыть направление: подтвердить, что объявленная поверхность инструментов
равна исполняемой, что схемы и промпт-профиль согласованы, что skills доходят
до агента без ослабления grant, и перенести подтверждённые контракты в
канонические документы.

1. Свести acceptance по каждому дефекту из `191-0`: мёртвые инструменты,
   заглушки схем, `git.commit`, `EXPECTED_TOOL_COUNT`, ASCII-only отбор,
   неиспользуемый `SelectionCache`, промпт без версии, `skill_context: &[]`.
2. Обновить `docs/architecture.md` (декларативный каталог, промпт-профиль,
   model-facing skill disclosure), `docs/current-state.md` (подтверждённое
   состояние checkout) и `docs/release-evidence.md` (focused evidence и
   честные unavailable gates) только после подтверждённого поведения.
3. Удалить файлы `docs/plans/191-*` и обновить `docs/plans/README.md`:
   следующий свободный номер и состав активного каталога.
4. Проверить, что затронутые публикуемые модули получили patch-версию по
   правилу `AGENTS.md`, а документационные и CI-only изменения — нет.

## Зависимости

### Блокирующие

Этапы 191.1–191.3 и focused test evidence по ним; актуальные
`docs/current-state.md` и `docs/release-evidence.md`.

### Опциональные

Внешний CI-прогон подтверждает acceptance после push, но не блокирует
подготовку закрытия; недоступный gate фиксируется как `unavailable`, а не как
`PASS`.

## Recovery и rollback

Закрытие не удаляет durable данные и не меняет trust-записи. Если acceptance
по какому-то дефекту не подтверждён, соответствующий этап не закрывается, а
пункт остаётся в плане. Откат документации выполняется возвратом прежней
формулировки, а не удалением истории evidence.

## Verification

Static: `git status`, `git diff`, `git diff --check`, разрешение внутренних
ссылок, сверка объявленных и зарегистрированных инструментов по исходникам.
Focused tests по этапам 191.1–191.3, включая negative security-набор для
skills. Ранее сохранённый `unavailable` gate остаётся `unavailable`.

## Release evidence

Зафиксировать: версии контрактов, итоговый список инструментов и их схем,
версию и hash промпт-профиля, версию словаря отбора, формат skill-секции,
focused test/CI результаты, изменённые release-версии модулей и подтверждение
security-инвариантов. Не сохранять raw prompts, тела скиллов, secrets и
абсолютные пути.

## Критерии выхода

- [ ] Каждый дефект из `191-0` подтверждён evidence либо явно оставлен
      открытым с причиной.
- [ ] Canonical docs обновлены только по подтверждённому поведению.
- [ ] `docs/plans/191-*` удалены, индекс планов обновлён.
- [ ] Внутренние ссылки разрешаются и `git diff --check` проходит.
