## Recovery и rollback

Неизвестная или недоступная команда в старом shell-клиенте даёт typed
`unavailable`, а не падение: добавление additive, старые сборки не ломаются.
Список читает только metadata; недоступная БД даёт пустой bounded ответ с
`error_code`, а не ошибку рендера. Rollback: удалить UI-запрос и пункт меню;
IPC-команда может остаться, так как является additive. Данные не мигрируют.
