# Визуальные референсы 3D-графики интерфейса Улья (Hive)

Набор визуальных референсов для проектирования 3D-элемента во вкладке «Улей» (`EvoHime`), отражающего концепции **«Автономного Наблюдения»** и **«Живого Улья»**.

Ориентир по цветам из текущей тёмной темы оболочки (`desktop/evohime-electron/src/renderer/src/styles.css`):
- фон: `#0d0d11` (`--bg`), `#0a0a0d` (`--bg-sunken`);
- основной фиолетовый акцент: `#8d82e8` (`--accent`);
- тёплый золотисто-янтарный акцент: `#e0b341` (`--warning`);
- вспомогательный бирюзово-зелёный статус: `#4ec9a4` (`--success`).

---

## 1. `hive_digital_honeycomb_v1.png` (1376×768)
- **Концепция:** «Цифровой Улей» (кристаллические соты).
- **Что взять за основу:**
  - полупрозрачная гексагональная структура с глубиной и внутренними световыми «жилками», создающими ощущение живого интеллекта;
  - мягкий цветовой переход между тёплым золотисто-янтарным и фиолетовым свечением;
  - чистый тёмный фон без лишнего HUD-шума.
- **Что избегать:**
  - асимметричных вытянутых кристаллов-«шипов» по периметру — в интерфейсе они выглядят как игровой артефакт или минерал, а не как спокойный системный компонент.

## 2. `hive_digital_honeycomb_v2.png` (1376×768)
- **Концепция:** «Цифровой Улей» (архитектурный минимализм).
- **Что взять за основу:**
  - модульный кластер из матовых обсидиановых и дымчато-стеклянных гексагональных призм;
  - тонкие, аккуратные золотые и фиолетовые швы свечения на стыках граней;
  - строгий инженерный характер, который гармонично вписывается в desktop-интерфейс и не перетягивает внимание от текста и контролов.
- **Что избегать:**
  - слишком глухих тёмных граней по краям — при интеграции стоит добавить деликатный rim-light, чтобы силуэт не сливался с `--bg-sunken`.

## 3. `queen_eva_crown_ethereal.png` (1024×1024)
- **Концепция:** «Королева Ева».
- **Что взять за основу:**
  - центральное тёплое золотое ядро, окружённое сферой из переплетённых фиолетовых и жемчужно-белых световых нитей;
  - ощущение спокойного контроля, централизации и оркестрации.
- **Что избегать:**
  - буквальной стеклянной «зубчатой короны» сверху — она делает образ слишком декоративным и фэнтезийным;
  - мелких «осколков» и космической туманности на фоне. В UI лучше оставить только абстрактные орбитальные дуги и сплетение нитей вокруг ядра.

## 4. `surveillance_24_7_pulse.png` (1376×768)
- **Концепция:** «Наблюдение 24/7».
- **Что взять за основу:**
  - концентрические HUD-кольца сканирования с аккуратными радиальными делениями и точками активности;
  - сочетание холодного сине-голубого контура мониторинга и тёплого янтарного ядра внутри полупрозрачной сферы;
  - читаемая метафора непрерывного фонового цикла (`EvaPulse`).
- **Что избегать:**
  - широких объёмных лучей, уходящих за границы композиции — в UI-карточке свечение должно оставаться компактным;
  - чрезмерно мелких штрихов, которые будут рябить на экранах без HiDPI.

## 5. `ipc_data_flow_nodes.png` (1376×768)
- **Концепция:** «Связь и IPC».
- **Что взять за основу:**
  - понятная топология «центральное ядро ↔ периферийные узлы» (визуализация связи Королевы с дочерними агентами и клиентами IPC);
  - плавные орбитальные траектории с направленными частицами, показывающими обмен данными;
  - единый золотой цвет активных ядер внутри узлов.
- **Что избегать:**
  - массивных «ленточных» хвостов и тяжёлого чёрного каркаса у центрального многогранника — в реальной 3D-сцене траектории и узлы должны быть воздушнее.

## Рекомендуемое направление и заметки по интеграции в Electron

- **Базовый визуальный язык:** за основу лучше взять **`hive_digital_honeycomb_v2.png`** (строгая архитектура, материалы и палитра EvoHime), дополнив его концентрическими кольцами сканирования из **`surveillance_24_7_pulse.png`** (индикация статуса `EvaPulse`) и тонкими потоками частиц к периферийным узлам из **`ipc_data_flow_nodes.png`** при активных child-агентах.
- **Технические ограничения для будущей интеграции:**
  - **Рендер вместо тяжёлой статики:** для UI предпочтительна лёгкая интерактивная WebGL/Three.js-сцена (или оптимизированный `.glb` + шейдеры), управляемая состоянием `HiveStateSnapshot`, а не встраивание полноразмерных PNG (`1376×768`, 1–1.7 МБ).
  - **Прозрачный фон и темы:** оболочка поддерживает `dark`, `light` и `system` темы (`styles.css`). Канвас 3D-сцены должен иметь прозрачный фон (`alpha: true`) и адаптировать контрастность граней для светлой темы.
  - **CSP и автономность:** все ассеты/текстуры должны лежать локально в бандле Electron без сетевых запросов.
  - **Энергоэффективность:** рендер должен приостанавливаться, когда вкладка «Улей» неактивна, окно свёрнуто или включён `prefers-reduced-motion: reduce`.
