# Дизайн оконного установщика EvoHime

## Цель

Установочный файл `evohime-setup.exe` должен открывать только компактное графическое окно без отдельной консоли Windows. Окно должно выглядеть как законченный установщик, а не как технический экран отладки.

## Объём

- Сохранить существующую фоновую установку на Tokio и канал `ProgressEvent`.
- Собрать installer как Windows GUI-приложение с subsystem `windows`, чтобы при запуске не появлялось консольное окно.
- Оставить существующий `egui`/`eframe` стек и переработать только визуальный слой `crates/installer/src/main.rs`.
- Сделать компактное окно около 520×420 с минимальным размером, тёмной палитрой, цветной шапкой EvoHime, заметной кнопкой установки, прогресс-баром и состояниями успеха/ошибки.
- Сохранить подробности установки в сворачиваемой области; при ошибке раскрывать её автоматически.

## Поведение

До старта отображаются название, краткое описание и кнопка «Установить». После старта интерфейс показывает статус, текущий этап, прогресс и журнал. В случае ошибки окно не закрывается само и показывает подробности. После успеха отображается подтверждение и путь к созданному ярлыку.

## Ошибки и ограничения

Ошибки фоновой установки продолжают передаваться через `ProgressEvent::Error`; новый UI не скрывает текст ошибки. Консоль не используется для пользовательского вывода. Установщик по-прежнему ограничивается одним экземпляром через существующий `SingleInstanceLock`.

## Проверка

- `cargo fmt --check` для затронутого Rust-кода.
- `cargo check -p evohime-installer` или release-сборка, если доступен Rust toolchain.
- Проверка PE-заголовка собранного `evohime-setup.exe`: subsystem должен быть `Windows GUI (2)`, а не `Console (3)`.
- Визуальный запуск собранного файла на Windows без появления отдельного окна терминала.
