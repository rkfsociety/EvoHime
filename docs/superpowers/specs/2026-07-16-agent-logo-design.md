# Логотип / маскот агента EvoHime

> Дата: 2026-07-16  
> Статус: draft (ожидает review)  
> Связь: frontend brand presence (UI shell)

## Goal

Дать EvoHime узнаваемого маскота и единый бренд-слой в UI: SVG-марка для системных слотов + растровый портрет цундере-химе для «лица агента». Максимальное присутствие везде, где сейчас голый текст бренда.

## Non-goals (v1)

- Отдельный маркетинговый лендинг
- Анимация маскота / смена эмоций по статусу задачи
- Замена всей типографики/темы UI под новый бренд
- Бизнес-логика на фронте (только презентация ассетов)

## Решения (зафиксировано)

| Вопрос | Выбор |
| --- | --- |
| Объём | Полный маскот: шапка + аватар + favicon + набор размеров |
| Персонаж | Аниме-девочка / химе |
| Характер визуала | Цундере: холодный взгляд, лёгкая ухмылка |
| Техника | Гибрид: SVG-марка + растр-портрет |
| Палитра | Холодная: серебристые/белые волосы, голубые/бирюзовые глаза под тёмный UI |
| Покрытие UI | Максимум: все места с брендом EvoHime |

## Подход

**Знак + портрет** (отклонённые альтернативы: один растр на всё; чистый SVG-персонаж).

- Мелкие/системные слоты → SVG-марка (читается на 16px).
- «Лицо агента» → растр-портрет (чат, empty, thinking).
- В одном крошечном слоте не дублировать марку и портрет.

## Ассеты

Каталог: `frontend/web/public/brand/`

| Файл | Назначение |
| --- | --- |
| `agent-mark.svg` | Марка: упрощённый фронтальный силуэт лица (не монограмма EH) |
| `favicon.svg` | Вкладка браузера (из марки) |
| `favicon.ico` | Fallback в `frontend/web/public/` (16/32) |
| `agent-avatar-256.webp` | Мастер-портрет |
| `agent-avatar-128.webp` / `agent-avatar-64.webp` | UI-слоты |
| `agent-avatar.png` | Опциональный fallback |

### SVG-марка

- Упрощённый фронтальный силуэт лица (волосы + глаза + намёк на ухмылку), без мелких ресниц/бликов и без буквенной монограммы.
- Цвета: серебро `#C8D4E6`, акцент бирюза/голубой в духе существующих CSS-переменных UI, фон прозрачный.
- Должна оставаться узнаваемой при 16×16.

### Растр-портрет

- Бюст/лицо цундере-химе: серебристые волосы, холодный взгляд, лёгкая ухмылка.
- Фон тёмный или прозрачный под shell.
- Генерация: 2–3 варианта image-tool → выбор пользователя → фиксация в `public/brand/`.

## Места в UI

| Место | Ассет |
| --- | --- |
| Top bar `.agentBrand` | Марка + текст «EvoHime» |
| Favicon / tab | `favicon.svg` / `.ico` |
| Сообщения агента в чате | Портрет-аватар |
| Empty chat / «агент думает» | Крупный портрет + короткая подпись |
| Sidebar / project chip «EvoHime» | Маленькая марка |
| Settings («Параметры EvoHime») | Марка в заголовке |
| Scheduled empty state | Маленькая марка у текста про EvoHime |

Правило: **марка** = системное/мелкое; **портрет** = лицо агента.
