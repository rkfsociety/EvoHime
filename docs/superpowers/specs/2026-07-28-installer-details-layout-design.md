# Дизайн адаптивного журнала установщика EvoHime

## Цель

Сделать раздел «Подробности» в `evohime-setup.exe` постоянно видимым,
читаемым при любом допустимом размере окна и пригодным для полного
копирования журнала установки.

## Интерфейс

- Минимальный размер клиентской области задаётся через
  `ViewportBuilder::with_min_inner_size([720.0, 720.0])` в логических points
  `egui`. При масштабе Windows, отличном от 100%, физическое число пикселей
  меняется, а доступный логический размер интерфейса остаётся `720×720`.
- Начальный размер клиентской области аналогично задаётся через
  `ViewportBuilder::with_inner_size([900.0, 720.0])`.
- Окно остаётся изменяемым по ширине и высоте.
- Раздел «Подробности» отображается постоянно до, во время и после установки
  и не имеет элемента сворачивания.
- До появления первой записи поле показывает визуальную заглушку
  «Журнал пока пуст.», которая не является содержимым журнала. Кнопка
  «Копировать всё» в этом состоянии недоступна.
- Заголовок раздела и кнопка «Копировать всё» находятся в одной строке.
- Поле журнала занимает всю доступную ширину и оставшуюся высоту окна.
- При изменении размеров окна поле журнала пересчитывает оба размера вместе
  с родительским интерфейсом.
- Длинный журнал прокручивается внутри поля, не увеличивая окно и не скрывая
  верхние элементы состояния установки.
- Длинные строки переносятся по доступной ширине поля. Горизонтальная
  прокрутка не используется, текст не обрезается.

## Прокрутка

При появлении записей журнал автоматически остаётся у нижнего края, пока
пользователь сам не прокрутит его вверх. После ручной прокрутки вверх новые
записи не меняют выбранную позицию. Автопрокрутка возобновляется, когда
пользователь возвращает журнал к нижнему краю.

## Копирование

Журнал отображается в многострочном поле только для чтения. Пользователь
может выделять его содержимое и использовать стандартные сочетания
`Ctrl+A` и `Ctrl+C`. Кнопка «Копировать всё» помещает в системный буфер весь
журнал одной операцией. Строки копируются в исходном порядке и разделяются
переводами строк; текст ошибки включается наравне с остальными событиями.
Текст, полученный кнопкой, полностью совпадает с содержимым отображаемого
журнала и не включает визуальную заглушку пустого состояния.

## Архитектура и ограничения

Изменение ограничивается визуальным слоем `crates/installer/src/main.rs`.
Фоновая установка, канал `ProgressEvent`, вычисление прогресса, сетевые
операции и обработка ошибок не меняются.

`InstallerApp` хранит полный журнал в единственном строковом буфере. Новая
запись дописывается в этот буфер только при обработке `ProgressEvent`, с
одним переводом строки между соседними записями. Поле только для чтения
показывает этот же буфер, а кнопка копирования передаёт его полную копию в
системный буфер. Отдельное представление для отображения не создаётся, и
полный текст не пересобирается на каждом кадре интерфейса.

## Проверка

- Модульный тест подтверждает инкрементальное формирование единственного
  текста журнала, включая порядок строк, разделители и ошибку.
- Проверка копирования подтверждает, что кнопка передаёт тот же полный текст,
  который отображается в поле, а при пустом журнале кнопка недоступна.
- Тест сначала должен упасть из-за отсутствующего поведения, затем пройти
  после минимальной реализации.
- `cargo test -p evohime-installer` проверяет затронутый crate.
- `cargo fmt --check` и `cargo check -p evohime-installer` подтверждают
  форматирование и сборку.
- Собранный установщик визуально проверяется в размере `720×720`, в
  начальном размере `900×720` и после увеличения окна по обеим осям.
- При визуальной проверке журнал должен занимать оставшуюся область,
  прокручиваться, позволять ручное выделение и полностью копироваться
  отдельной кнопкой.
- Изменение размеров окна не приводит к перекрытию поля журнала заголовком,
  кнопкой копирования, статусом или индикатором прогресса; верхние элементы
  остаются видимыми при минимальном размере.
- В журнале с числом записей, превышающим высоту поля, проверяется условная
  автопрокрутка: удержание нижнего края, сохранение ручной позиции выше и
  возобновление после возврата вниз.
- Длинная строка переносится по ширине поля без обрезки и горизонтальной
  полосы прокрутки.
