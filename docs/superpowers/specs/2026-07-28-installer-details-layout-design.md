# Дизайн адаптивного журнала установщика EvoHime

## Цель

Сделать раздел «Подробности» в `evohime-setup.exe` постоянно видимым,
читаемым при любом допустимом размере окна и пригодным для полного
копирования журнала установки.

## Интерфейс

- Минимальный внутренний размер окна установщика — `720×720`.
- Начальный внутренний размер окна — `900×720`.
- Окно остаётся изменяемым по ширине и высоте.
- После начала установки раздел «Подробности» всегда развёрнут и не имеет
  элемента сворачивания.
- Заголовок раздела и кнопка «Копировать всё» находятся в одной строке.
- Поле журнала занимает всю доступную ширину и оставшуюся высоту окна.
- При изменении размеров окна поле журнала пересчитывает оба размера вместе
  с родительским интерфейсом.
- Длинный журнал прокручивается внутри поля, не увеличивая окно и не скрывая
  верхние элементы состояния установки.

## Копирование

Журнал отображается в многострочном поле только для чтения. Пользователь
может выделять его содержимое и использовать стандартные сочетания
`Ctrl+A` и `Ctrl+C`. Кнопка «Копировать всё» помещает в системный буфер весь
журнал одной операцией. Строки копируются в исходном порядке и разделяются
переводами строк; текст ошибки включается наравне с остальными событиями.

## Архитектура и ограничения

Изменение ограничивается визуальным слоем `crates/installer/src/main.rs`.
Фоновая установка, канал `ProgressEvent`, вычисление прогресса, сетевые
операции и обработка ошибок не меняются. Текст для отображения и кнопки
копирования формируется одним общим способом, чтобы содержимое поля и
буфера обмена не расходилось.

## Проверка

- Модульный тест подтверждает формирование полного текста журнала, включая
  порядок строк, переносы и ошибку.
- Тест сначала должен упасть из-за отсутствующего поведения, затем пройти
  после минимальной реализации.
- `cargo test -p evohime-installer` проверяет затронутый crate.
- `cargo fmt --check` и `cargo check -p evohime-installer` подтверждают
  форматирование и сборку.
- Собранный установщик визуально проверяется в размере `720×720`, в
  начальном размере `900×720` и после увеличения окна по обеим осям.
- При визуальной проверке журнал должен занимать оставшуюся область,
  прокручиваться, позволять ручное выделение и полностью копироваться
  отдельной кнопкой.
