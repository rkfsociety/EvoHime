# Оконный установщик EvoHime Implementation Plan

> **Для агентных исполнителей:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` (inline execution) or `superpowers:subagent-driven-development` to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Цель:** убрать консоль Windows у установщика EvoHime и улучшить оформление его компактного окна.

**Архитектура:** существующий `eframe`-бинарник остаётся единственным пользовательским процессом. В Windows-часть сборки добавляется GUI subsystem, а `InstallerApp` получает более выразительный, но не меняющий логику установки слой отрисовки.

**Стек:** Rust 2021, `eframe 0.35`, `egui`, Tokio, Cargo, Windows PE.

## Глобальные ограничения

- Не менять фоновую логику установки, загрузки архивов, SHA256-проверки, PostgreSQL и ярлыка.
- Не добавлять WebView2/Tauri или отдельный runtime.
- Не показывать пользователю консольное окно.
- Не редактировать сгенерированные протоколы и не затрагивать несвязанные crates.
- После проверки удалить workspace `target/`, если он не нужен последующей проверке.
