# Auto sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Финальная волна `7.99`: фоновый цикл авто-push backup для bootstrap owner по `EVOHIME_SYNC_AUTO_MINUTES`, с `auto_minutes` в `/api/sync/status`.

**Architecture:** Push-логика handler-а выносится в переиспользуемый `perform_push(state, operator_id, config)`; handler и новый `auto_sync_loop` вызывают её. Цикл спавнится в `startup.rs` рядом со scheduler/metrics loops только при ненулевом интервале (min 5 минут).

**Tech Stack:** Rust/tokio interval loop, существующие `SyncConfig`/`sync_runs`.

## Global Constraints

- Не создавать новую ветку; работать в текущей `main`.
- Ошибки цикла логируются, не паникуют; активный run оператора пропускает тик.
- Push не выполнять без прямого запроса пользователя; после каждой законченной задачи создавать коммит.
