Все инструменты разработки находятся в общей папке `F:\github\PROG`:

- **Android SDK**: `F:\github\PROG\Android\Sdk`
- **JDK 17**: `F:\github\PROG\Java\jdk-17.0.19+10`
- **Gradle cache**: `F:\github\PROG\cache\gradle`
- **sdkmanager**: `F:\github\PROG\Android\Sdk\cmdline-tools\latest\bin\sdkmanager.bat`

Если какого-то компонента не хватает, скачиваем его туда же в `F:\github\PROG`.
