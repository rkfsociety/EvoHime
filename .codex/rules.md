# Правила Codex проекта EvoHime

Корневой `AGENTS.md` является полным источником правил разработки. Этот файл
содержит только дополнительные ограничения для проектной памяти и не
дублирует общий инженерный протокол.

- Долговременные знания Codex хранятся в `.codex/memory.md`; канонические
  сведения о продукте и реализации остаются в `docs/` и исходниках.
- Записывай только подтверждённые и полезные для будущих задач факты с
  указанием канонического источника, если он не очевиден.
- Не сохраняй в `.codex` секреты, токены, персональные данные, кэши, временные
  файлы, историю действий или незавершённые рассуждения.
- При противоречии между памятью и текущим кодом сначала проверяй код и тесты,
  затем обновляй устаревшую запись памяти.
- Перед изменениями сохраняй пользовательские dirty-изменения и соблюдай
  правила task-only commit из `AGENTS.md`.
- Production Rust targets во всём workspace не должны использовать `unwrap`,
  `expect` или `panic`; crate roots закрепляют это через
  `cfg_attr(not(test), deny(...))`. Build scripts возвращают ошибки через
  `Result`. Внутренние и интеграционные тесты могут использовать эти вызовы.
