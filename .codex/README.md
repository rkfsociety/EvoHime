# Project Codex metadata

Эта папка является отслеживаемой Git-точкой для переносимых инструкций и
заметок, относящихся к проекту EvoHime.

Канонические правила разработки находятся в корневом `AGENTS.md`, а описание
архитектуры и состояния — в `docs/`. В `.codex` нельзя сохранять секреты,
токены, ключи, персональные данные, машинные кэши и временные артефакты.

Проектная память минимальна: после завершения временного плана его детали не
хранятся в `.codex`, а переносятся в `docs/architecture.md`,
`docs/current-state.md` или `docs/release-evidence.md`. Текущая работа и
решения должны быть видны в этих канонических документах, а не в архивных
дублях.

## Проектные skills

Расширенные инструкции для полного закрытия implementation plan хранятся в
`.codex/skills/` и отслеживаются Git вместе с исходниками. Для запроса вида
«полностью реализовать и закрыть план» основной вход —
`evohime-plan-implementation/SKILL.md`; он маршрутизирует работу к
специализированным skills:

- `evohime-repo-orientation` — синхронизация, ветка, dirty tree, правила и
  источники истины до любых изменений;
- `evohime-plan-review` — итерационное ревью и исправление канонического плана;
- `evohime-implementation-audit` — сопоставление требований с кодом,
  тестами, CI, runtime, IPC, упаковкой и документацией;
- `evohime-ci-evidence` — чтение workflow и доступных CI-run без локального
  запуска проверок;
- `evohime-module-release-routing` — карта затронутых публикуемых модулей,
  patch-версии и условия module router;
- `evohime-static-verification` — статическая финальная проверка с запретом
  локальных тестов, сборок, линтеров и smoke-прогонов;
- `evohime-documentation-closure` — перенос контракта, состояния и evidence,
  удаление реализованного плана и проверка устаревших ссылок;
- `evohime-task-only-commit` — безопасная фиксация только относящихся к задаче
  файлов в текущей ветке без push.

Skills намеренно не хранят секреты, токены, абсолютные пользовательские пути,
кэши или снимки CI. Перед каждым применением нужно заново читать текущие
`AGENTS.md`, `.codex/README.md`, `docs/README.md`, `docs/plans/README.md` и
затронутые workflow: проектные файлы являются источником истины, а этот набор
skills — маршрутизацией и контрольным списком.
